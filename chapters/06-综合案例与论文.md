## 10. 综合知识备考方法

### 10.1 三轮策略

第一轮（W03～W44）：

- 章节学习后立即做题。
- 正确率目标从 50% 逐渐提高到 65%。
- 重点是覆盖全部大纲，不因某一章困难停两个月。

第二轮（W45～W54）：

- 分类真题与完整年度题结合。
- 每次把错误映射回教材章节。
- 将高频计算、易混概念、标准法规压缩成个人笔记。

第三轮（W55～W60）：

- 严格计时做完整卷。
- 训练 120～130 分钟内完成综合，把更多时间留给案例。
- 不再系统观看新课程，只补真实失分点。

### 10.2 单选题处理

- 第一遍做确定题，单题超过 90 秒仍无思路就标记。
- 计算题先写单位、公式和已知量，避免直接心算。
- 遇到绝对化表述要谨慎，但不能把“绝对化就错”当成规则。
- 专业英语先看问题和选项，再定位原文关键词。
- 模糊题先排除明显错误项，不在一题上消耗案例时间。

## 11. 案例分析备考方法

### 11.1 标准答题结构

大多数问答可按以下结构：

```text
结论：明确写出方案、问题或术语。
依据：引用题干中的业务、约束、指标或现象。
理由：说明为什么产生问题或为什么方案有效。
措施：按 1、2、3 分点，使用规范术语。
效果/代价：说明改善的质量属性及引入的成本或风险。
```

### 11.2 案例训练的四遍法

1. 闭卷限时作答。
2. 对照参考答案标出评分关键词。
3. 回到教程找知识来源，不只抄答案。
4. 24 小时后只看题干重新作答。

### 11.3 选答题策略

- 先用 3～5 分钟浏览所有题，判断“会的分值”而不是判断题目看起来熟不熟。
- 优先选择能写出具体技术措施和理由的题。
- 对嵌入式、通信等非主攻方向，保留基础得分能力，但不为了少量可能分值投入过多时间。
- 每道题按分值控制答案点数，6 分问题通常至少准备 3～6 个明确得分点。

## 12. 论文备考系统

### 12.1 项目素材必须来自真实经历

可以对真实项目信息脱敏，并从系统角度补充自己实际参与、调研或验证过的架构工作；不能背一篇完全不理解的虚构范文。项目素材表至少包含：

| 维度 | 要记录的内容 |
| --- | --- |
| 业务背景 | 用户是谁、解决什么问题、为什么建设 |
| 规模 | 用户量、并发、数据量、团队、工期；不清楚就查真实资料，不凭空夸大 |
| 本人职责 | 需求讨论、技术调研、方案设计、前端架构、接口、安全、性能或部署中的真实工作 |
| 关键约束 | 工期、旧系统、预算、团队能力、合规、兼容性 |
| 质量目标 | 响应时间、可用性、恢复时间、安全、可修改性 |
| 架构方案 | 风格、模块、数据、通信、部署 |
| 决策权衡 | 为什么选择；放弃什么；引入什么代价 |
| 问题与解决 | 故障、性能瓶颈、需求变化、数据一致性、协作问题 |
| 结果 | 指标变化、交付效果、遗留问题和改进计划 |

### 12.2 八个优先主题

1. 软件架构风格及其应用。
2. 系统质量属性与架构评估。
3. 微服务或面向服务架构。
4. 云原生架构。
5. 高可用、可靠性与容错。
6. 安全架构。
7. 数据架构、大数据或缓存/消息应用。
8. 架构演化、系统集成或遗留系统改造。

正式考试主题可能不同，所以训练重点是“一套项目素材如何按题意重新组织”，不是背八篇固定范文。

### 12.3 训练用结构

具体字数以 2027 年试题要求为准。平时可按以下目标训练：

```text
摘要：约 300～350 字
正文：约 2200～2600 字

一、项目背景和本人职责
二、题目要求的理论或方法概述
三、结合项目逐项论述实施过程（全文核心）
四、效果、问题、改进与总结
```

正文第三部分必须占最大篇幅，并逐条回应题目给出的子问题。

### 12.4 每篇论文自评表

每项按 0～2 分检查：

- 是否完整回应题目全部子问题。
- 摘要是否直接交代项目、职责、方法和结果。
- 项目背景是否具体可信。
- 本人是否是架构工作参与者，而非旁观者。
- 每个理论点是否都有项目措施对应。
- 是否写出选择理由和权衡。
- 是否出现量化或可验证结果。
- 是否有问题、局限和改进，而非全程完美。
- 段落标题和逻辑是否清楚。
- 是否在 120 分钟内完成并留出检查时间。

低于 14 分的论文必须重写，不只是修改错别字。

### 12.5 机考输入训练

- 从 W44 起每周至少一次 20 分钟连续中文输入。
- W50 起全部论文直接在电脑上写，不先手写全文。
- 目标不是盲目追求打字速度，而是 100 分钟写完主体、15 分钟补充、5 分钟检查。
- 熟悉机考系统允许的图形输入方式和编辑操作；以当年官方模拟系统为准。
