# 练习与真题使用规范

仅在实际准备出题、复习、分析错题、检查周计划阈值，或判断一题是否可计分时读取本文件。普通知识讲解不必读取，也不因核心或重要知识点已经理解而自动安排真题。

## 项目数据路由

按下列顺序取证，不从网页展示文本反推数据：

1. `data/week-evidence.json`：唯一的 W01—W40 证据映射。读取当前周的考纲页码、32 小时范围、必做/选做题、练习类型、题目页码、答案页码、可信度和当周阈值。
2. `data/question-bank-status.json`：逐年确认题库是否完整、哪些题可计分及有哪些警告。状态为 partial 不等于其中每题都不可用，必须继续核对具体题。
3. `materials/local/question-bank.v1.json`：本地完整题库数据源。根据年份和题号读取题干、选项、答案、解析、原题页码和解析页码。网页发布副本 `html/local/question-bank-data.js` 只用于检查展示一致性，不作为编辑源。
4. `data/question-index.json`：用于快速定位年份、题号和 PDF 页码。它的 snippet 仅用于检索，不可代替完整题面。
5. `html/practices.html?week=Wxx`：学习者实际做题入口。需要查看原版排版、公式或图片时，使用题目上的“查看 PDF 原题”链接。

如果结构化题库、索引、周映射和 PDF 原页不一致，先停止判分并核对 PDF；不要自行补造缺失题干、选项、图、公式或答案。

### 计划周与证据周

- `当前计划周`按日期表示计划运行到哪里；`知识点对应证据周`按章节、教材范围和学习目标表示本知识点应该使用哪一周的练习。两者可以不同。
- 选择题目时必须使用知识点对应证据周，不能机械使用当天的计划周。例如当前计划周为 W01、项目正在辅导第二章硬件与存储时，证据周是 W02；W01 仍保持“外部学习”，不得把第二章练习写入 W01。
- 优先用 40 周计划中的章节范围和 `data/week-evidence.json` 的 `textbookPages`、`guideSection`、题目标签共同确认。跨周知识点选择其主要学习目标所在周；存在歧义时明确写出选择依据，不重复计入两个周的必做题。
- 发生实际练习时，在学习日志中同时记录当前计划周和知识点对应证据周；网页练习入口使用证据周参数。

## 资料可信度与用途

- `official`：考试大纲，只确定范围与能力要求，不提供题目难度或频率结论。
- `published-guide`：32 小时辅导书，用于压缩理解和在正式题不足时补题，不能取代主教材。
- `historical-paper`：题面可用于练习；只有题库中存在已核实答案且未被状态警告排除时才可计分。第三方解析与新版教材冲突时标记`解析争议`。
- `recall`：回忆或还原题只用于观察命题表达和趋势，不计分，不用于补足题量，不据此声称“高频”或“必考”。必须在正式练习完成后再看。

已知整卷限制：

- 2009—2018 年用于章节训练；具体可计分情况以 `data/question-bank-status.json` 和题目记录为准。
- 2019 年安排在 W36 作诊断。当前答案仅由 OCR 定位、尚未逐题视觉核验时，整卷不得自动判分，也不作阶段失败判定。
- 2020 年资料是不完整回忆题集，不得伪装成 75 题完整试卷。
- 2021 年资料不完整，缺失题目不得生成或纳入分母。
- 2023、2025 年回忆题只作趋势线索，不计入正确率。

## 代表题选择

1. 先限定当前最小知识点及其知识点对应证据周，不因同属一章就拿无关题。
2. 优先顺序为：`required` 且可计分的历史真题 → `optional` 且可计分的历史真题 → 32 小时对应练习。回忆题不用于首次验证。
3. 同等相关时优先较新年份，但不能只为年份新而牺牲知识点匹配。
4. 一轮默认只给一组代表题。连续小题共享题干时作为一组呈现，不能拆开，也不能把一组中的部分答案提前泄露。
5. 有图、表、公式、特殊符号或 OCR 可疑内容时，先视觉核对原 PDF 页；网页题面旁保留原题跳转入口。
6. 不重复计入同一道题。题目可以有次级知识标签，但只按映射中的主周次参与必做统计。

## 出题与解析格式

出题前先用三行完成考试翻译：

- `考查动作`：识别、辨析、计算、记忆、场景判断中的一种或两种。
- `题干信号`：本题中提示应该调用该知识的关键词、条件或关系。
- `易错点`：最可能混淆的一个概念、条件或计算步骤。

随后展示完整题面、选项、年份与题号，但不展示答案和解析。要求学习者同时给出选项和简短理由；答案只有在提交首次作答后解锁。

作答后：

1. 明确正误，但先说明学习者的判断链哪里成立或断裂。
2. 回连教材定位和原文，说明正确结论来自哪个定义、条件、公式或步骤。
3. 只分析实际造成困难的选项；学习者要求完整复盘时再逐项解释。
4. 错题按一个主要错因记录：`概念混淆`、`题干误读`、`计算错误`、`记忆遗漏`、`解析争议`。
5. 首次结果永久保留。解释后安排重做原题或一题同考点变式，并把重做成绩单独记录。

若答对但理由明显错误、缺失或与选项无关，视为`待巩固`，不能以猜中记为本题掌握。

## 结果与达标口径

- 代表题结果：答对且能说明关键理由可记为本题掌握；猜中或答错记为待巩固。题目结果只服务于复习决策，不要求每个知识点都有一条验证状态。
- 周练习：以 `data/week-evidence.json` 知识点对应证据周的 `threshold.percentage` 为准，不把单题达标替代周达标。分母只包含实际存在且可计分的题。
- W36：2019 年整卷仅作诊断，不把未达阈值写成阶段失败。
- W39、W40：计划目标为 52/75、最低 48/75；若本地资料不完整，则必须明确显示“资料不完整，无法形成正式 75 题成绩”，只报告已作可计分题的结果，不能折算或补造整卷分数。

## 复习顺序

复习时按以下顺序投入：

1. 概念状态为`需复习`，或已有练习结果显示待巩固的核心知识点。
2. 当周必做题中的错题和未做题。
3. 已理解但在本周必做范围内尚未完成练习的核心、重要知识点。
4. 选做历史题与 32 小时补题。
5. 正式练习完成后，最多查看当周三道回忆题或一个趋势摘要。

不要用重复刷同一题产生的记忆正确率冒充迁移能力。重做原题通过后，核心概念若条件允许再用不同问法验证一次。
